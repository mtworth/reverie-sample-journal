# Reverie: a sample journal

A read-only demo of Reverie, a quiet companion for musical sketching. Open `index.html` (or the GitHub Pages site).

## Credits

- Music: MIDI transcriptions from the ATEPP dataset (Zhang, Tang, Dai, Fazekas; ISMIR 2022), CC BY 4.0. Excerpts are the openings of the pieces, cut to 10–16 seconds.
- Piano sound: Salamander Grand Piano by Alexander Holm, CC BY 3.0, via Tone.js (MIT).
- The "sounds alike" model is a small student distilled from Aria (EleutherAI, Apache-2.0) on GiantMIDI-Piano and ATEPP windows (both CC BY 4.0).
